# pixelpulse
Features
🔎 Live search against a public API on submit
🖼️ Responsive image grid (CSS Grid, auto-fill)
⏳ Loading skeletons while results load
🚫 Friendly empty and error states
📱 Mobile-friendly, dark, animated UI — no dependencies
How it's built
File	Role
index.html	Structure: header, search form, status line, results grid
styles.css	Styling: gradient header, responsive grid, cards, skeletons
script.js	Behaviour: fetch on search, render cards, handle loading/empty/error
This project is built across three lessons in Kalvium's Frontend Web Development course:

Scaffold & UI — repo + the search UI (HTML & CSS)
Fetch & Render — fetch results and render them into the grid
Polish, Error States & Deploy — loading/empty/error states, then ship it
Run locally
Open index.html in a browser, or serve the folder with any static server (e.g. VS Code's Live Server).
